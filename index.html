A flyer export has the wrong date. An App Store screenshot still shows last week’s price. A product photo has a typo in the burned-in label. You do not have the Figma file — only a flat JPG or PNG — and you need the words that are already in the picture changed, not a new caption stacked on top.

This guide walks through editing text that is already part of an image, in the browser, without creating an account. You will see when an in-place edit is realistic, when a remove-then-retype pass looks cleaner, and how to keep fonts and contrast from looking pasted on.

Edit-in-place vs add a new overlay

If the letters are still selectable layers in Canva, Photoshop, or the original design tool, edit there. When you only have pixels, you have two browser paths:

  • In-place edit — detect the existing line, replace the wording, and blend the new letters into the same spot. Best when the background behind the text is fairly simple.
  • Remove, then add — erase the old words first, then place a fresh line. Best when the old type sits on a busy photo, a gradient, or a textured pack shot.

Both can be done online for free. Pick the path that matches the plate, not the path that sounds fancier.

How to edit text in an image online (step by step)

  1. Open the free PhoText image text editor. Use a desktop or laptop browser when you care about alignment; phone is fine for a short one-line fix.
  2. Upload the picture. Work on a copy of anything you cannot afford to lose. JPG and PNG product shots and screenshots are the everyday case.
  3. Select the text you want to change. Aim at the burned-in line — headline, price, date, or UI label — not at empty sky where a caption would go.
  4. Type the new wording. Keep length close to the original when the layout is tight (prices, badges, button labels). Longer replacements may need a smaller size or a remove-then-retype pass.
  5. Match size, weight, and color as closely as the tool allows. If neighboring type is a specific font you must echo, identify it with the free Font Finder (no login, no usage cap), then style the replacement toward that lookalike.
  6. Export at the same resolution you uploaded. Spot-check on a phone-width preview. If the file is enormous before you start, shrink it with the free image resizer, edit on the clearer plate, then use that result downstream.

When remove-then-retype looks better

  • Busy backgrounds — fabric, foliage, crowd scenes, or noisy UI chrome behind the letters.
  • Heavy perspective or curved type — storefront signs shot at an angle, bottles, cans.
  • Large wording changes — “$19.99” → “Contact us for pricing” will not fit the old box cleanly.
  • Multiple lines that share one fill — erasing the block once, then placing one clean new block, beats fighting three half-edits.

For that path: run a remove text from image pass first, then place a fresh line with add text to image. Same free, no-login tools — just sequenced for a cleaner plate.

Tips that keep edited text from looking fake

  • Respect the original alignment. Centered badges stay centered; left-aligned UI labels stay left.
  • Do not invent a new color story. Sample from nearby letters or UI chrome instead of dropping in brand-new neon.
  • Watch edges. Soft halos and hard rectangular patches are the usual tell that someone painted over a mistake. A proper remove pass reduces that.
  • Proof at thumbnail size. Marketplace tiles and chat previews hide fine kerning problems but expose contrast failures.
  • Keep the source file. Flat exports are not re-selectable later. If wording may change again next week, save the original upload.

What not to expect

Browser editors are strong on flat marketing stills and UI screenshots. They are weaker on tiny engraved metal type, extreme perspective, or legally locked brand systems that require the licensed font file. If the asset will ship to print with a strict type ramp, edit the source design — do not treat a JPEG rescue as the brand system of record.
